The Core Insight

Two layers. One superpower.

PocketRAG doesn't replace your agent's intelligence — it feeds it. A grounding layer guarantees the facts; your reasoning layer does the work.

Layer 1

The Grounding Layer

NotebookLM · Discovery Engine API

When your agent calls ask_notebook, the RAG backend does the heavy lifting:

  • High-fidelity retrieval & OCR (even scanned PDFs)
  • Extracts the raw, verifiable facts
  • Returns a strictly grounded, hallucination-free result
  • Documents never bloat the agent's context window
Layer 2

The Reasoning Layer

Claude Code · Cursor · Gemini

Your agent receives those grounded facts and reasons over them to do real work:

  • Code generation — implement a spec it just retrieved
  • Refactor & debug against documented rules
  • Multi-step workflows — query, test, run, write
  • Edits local files & runs terminal commands
Grounded facts Reasoned action
The "Aha!" Synergy

A software architect with a perfect memory.

Your agent never guesses or forgets the specs — because an instant, managed RAG backend feeds it 100% accurate facts on demand. It keeps every ounce of its reasoning, coding, and execution power, but loses its only weakness: hallucination.

The Problem

Smart agents, unreliable memory.

Reasoning models are brilliant — until you stuff a 60-page PDF into their context and they start inventing details.

Agent Alone

  • Hallucinates facts from large documents
  • Loses details when the context window fills up
  • No managed retrieval — you build the RAG yourself
  • Re-uploads the same docs every session

Agent + PocketRAG

  • Grounded, OCR-verified facts on demand
  • Docs live in the RAG, not the context window
  • Zero-infra managed RAG via your GCP project
  • Reuse staged notebooks across sessions
Capabilities

Built for reasoning agents.

One Tool: ask_notebook

Your agent calls it like any other tool. Grounded facts come back as the tool result — ready to reason over, refactor, or implement.

  query="list all endpoints + auth"
